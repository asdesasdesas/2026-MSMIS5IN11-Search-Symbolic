# Licence du code - décision requise

Les deux membres doivent **choisir et approuver** la licence applicable à leurs contributions avant publication.
Proposition simple pour un projet pédagogique : MIT (si les deux auteurs acceptent et si les éléments réutilisés le permettent).
Le projet comprend des bibliothèques tierces sous leurs propres licences ; les données SocioPatterns restent sous
leur licence indépendante, présentée dans `data/README.md`.

Tant que ce choix n'est pas validé, ne pas présenter « MIT » comme licence effective du code et ne pas publier une licence au nom de l'autre personne sans son accord.
